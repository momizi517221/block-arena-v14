# BLOCK ARENA V14 ONLINE

V13を基にしたブラウザTPS/FPSのオンライン対応版です。Node.js + ws、外部描画ライブラリ・外部モデル・音声素材・DBは不要です。最大16人、10人程度での運用を目標にしています。

## ローカルで起動

Node.js 22以上とGitを用意し、このフォルダで次を実行します。

```sh
npm install
npm test
npm start
```

`http://localhost:3000/` をブラウザで開きます。2つ以上のウィンドウで別々のプレイヤー名を設定し、ONLINE PLAYを押せば同じアリーナに参加します。TRAININGは従来の練習モードです。サーバーの動作確認は `/health` で行えます。LAN内の接続テストとインターネット公開は別です。

## 初回の公開（GitHub + Render）

1. ZIPを展開し、GitHub上の新規リポジトリをクローンしたフォルダにファイル一式（隠しファイル.gitignoreを含む）を置きます。node_modules、認証情報、個人ファイルをアップロードしないでください。初期ブランチはmainとします。
2. `npm install` と `npm test` を実行し、package-lock.jsonを生成します。2つのブラウザで接続・移動・射撃・撃破・復活・切断を確認し、可能なら10～16クライアントで負荷試験します。
3. mainブランチへコミット・プッシュします。
4. RenderのWeb Service作成画面でGitHubリポジトリを選択します。Name: 任意（例 block-arena）、Runtime: Node、Region: Singapore（利用可能なら）、Branch: main、Root Directory: 空欄、Build Command: `npm ci --omit=dev`（lockfile生成前は `npm install --omit=dev`）、Start Command: `npm start`、Instance Type: Free。Health Check Path: `/health`、自動デプロイ: 有効。render.yamlを使う場合もFreeのまま設定を確認してください。
5. デプロイに成功したらRenderが発行したHTTPS URLを開き、別回線から対戦できることを確認します。固定URLは発行された実物を共有します。無料枠の制限や休止、地域の提供状況は管理画面で確認し、有料プランは契約しません。

## 2回目以降の更新

ChatGPTから受け取った更新ファイルを、初回のGitリポジトリフォルダに同じ構造で上書きしてください（.gitを消さない）。`UpdateGame.bat` をダブルクリックし、変更ファイルとremoteを確認してYを押すと、指定ファイルをコミットしてorigin/mainへプッシュします。Renderの自動デプロイが成功すれば同じURLが更新されます。開発者が別の変更を加えていた場合は、上書き前にその最新版をChatGPTへ共有してください。自動デプロイで対戦中のセッションが切断される場合があるため、プレイ中の更新は避けてください。

## 操作

WASD:移動 / 矢印:視点 / Space:射撃 / Shift:ジャンプ / T:FPS・TPS / Esc:設定。
標準ゲームパッド: 左スティック:移動 / 右スティック:視点 / RT・R2:射撃 / A:ジャンプ / Start:設定 / Back:視点切替。設定メニューは方向キー・Aで操作できます。タッチ操作はタイトルのチェックボックスまたは設定から有効化します。

## 対戦仕様（初期値・調整可能）

全員が同じ公開URLの1つのアリーナに参加する個人戦。プレイヤー名とウサギ・パンダ・犬を選択。HP100、通常弾20ダメージ、射撃間隔0.18秒（30Hz単位で処理）、撃破後3秒で復活、制限時間なし。サーバーがHP・キル・衝突・命中を管理し、クライアントからは入力だけを受け取ります。オンラインでは管理者設定を無効にし、全員共通の条件にしています。練習の管理者用パスコード0000はローカルUIの設定制限であり、認証ではありません。射撃位置補正は公平性を考慮してオンラインでは無効にしています。URLを知っている人は誰でも参加できるため、公開範囲を制限したい場合はルームコードや認証を追加してください。切断時はタイトルに戻り再参加可能ですが、スコアは引き継ぎません。スコア等の永続保存はありません。

## 軽量化

- サーバー更新30Hz、状態配信20Hz。状態は8バイトのヘッダーと32バイト/人のバイナリ形式。10人なら1配信328B、全10人宛てで約65.6KB/秒（状態データ部分のみ）。
- クライアント予測・サーバー補正・他プレイヤー補間。通信遅延の巻き戻し判定は未実装。
- 描画と音はクライアント側。モデルとアニメーションのメッシュをキャッシュし、画面外のモデルを描画しない。パーティクル450個上限、音声同時発音上限、描画解像度設定。
- メッセージ長、頻度、最大人数、滞留量を制限し、切断や無入力時を処理。無料ホスティングでの実測は必要です。

## ファイル

- server.js: HTTP公開、WebSocket接続、配信、ヘルスチェック
- simulation.js: 対戦処理、サーバー権威
- public/shared.js: 共通物理、命中判定、カメラ、状態パケット
- public/game.js: ゲームクライアント、UI、予測・補間・描画
- public/models.js / audio.js: 既存V13から移植したローポリ形状と効果音
- public/index.html / style.css: タイトル、HUD、設定、対戦UI
- test/match.test.js: 対戦シミュレーションとパケット形式テスト
